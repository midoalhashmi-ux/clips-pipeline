# خط الإنتاج الأسبوعي

كل خميس تلقائياً (أو يدوياً من تبويب `Actions` ← `Weekly content production` ← `Run workflow`) يُنتج فيديو عمودي لكل عمل مفعّل في `queue.json` تقع تواريخه خلال 7 أيام.

**المخرجات**: مجلد `ready-clips` في صفحة التشغيل (يبقى 30 يوماً)، فيه لكل عمل `video.mp4` و`meta.txt` (العنوان والوصف والوسوم وتعليق المنصات الأخرى).

**المسار المجاني (المعتمد)**: يكتب Claude Code النصوص مرة أسبوعياً داخل بند كل عمل بالحقول `speech` و`title` و`description` و`tags` و`short_caption`، فيتجاوز الخط واجهة Claude API. حين يغيب `speech` يُستعمل `ANTHROPIC_API_KEY` (اختياري ومدفوع).

**الأسرار المطلوبة** بإعدادات المستودع: `GEMINI_API_KEY` للصوت `Charon` فقط (مجاني). `ANTHROPIC_API_KEY` اختياري.

**إضافة عمل**: انسخ بند المثال في `queue.json`، واجعل `enabled` يساوي `true`، وضع `date` ومصدر الفيديو الرسمي `source_url` وملخصاً حقيقياً `synopsis` (Claude لا يكتب إلا منه، لمنع الأخطاء).

**الخاتمة لكل منصة**: صور حقيقية في `outro/` (راجع README هناك)؛ لكل منصة لها صورة تخرج نسخة `video-<المنصة>.mp4` بخاتمة تدعو لفتح القناة/الصفحة والضغط على الرابط.

**اختبار التركيب محلياً بلا مفاتيح**: `python tools/autoproduce/produce.py --dry-run`.

**حدود النسخة الأولى**: بلا كتابة مدمجة بالصورة، والرفع إلى يوتيوب يدوي ثم تتولى الجدولة الحالية الباقي.

**الأسلوب البصري**: راجع `مهارة التسويق في المشروع الرئيسي` (خط Cairo، عنوان بلون العمل، جملة بيضاء كبيرة أسفلها).

**النشر والجدولة**: راجع قسم «النشر والجدولة الآلية» في المهارة `مهارة التسويق في المشروع الرئيسي`.

**ملف معلومات الحدث (تفاصيل خفية موثّقة)**: `dossier.py` يجمع لكل حدث في `dossier_jobs.json` مادة خاماً مجانية من `AniList` و`Jikan` وويكي `Fandom`، ثم (مع `ANTHROPIC_API_KEY` فقط) يبحث بالويب ويدقق كل تفصيل في استدعاء مستقل ويكتب نص مقطع الشرح. بلا مفتاح يحفظ `dossiers/<key>.raw.json` فقط، ويكمل Claude Code البحث والتدقيق مجاناً داخل الجلسة. التشغيل من `Actions` ← `Event dossier (deep details)`، والنتائج في `dossiers/` (تقرير `.md` عربي للمراجعة). لا يضيف شيئاً إلى `queue.json` قبل مراجعة المالك.
