# صور الخاتمة لكل منصة

ضع هنا لقطة شاشة **حقيقية** لصفحة كل منصة تُظهر رابط التحميل: `youtube.png` و`instagram.png` و`facebook.png` و`tiktok.png`.

القواعد (من `docs/marketing/publishing-policy.json`): تبقى صورة الحساب واسمه والرابط ظاهرة، وتُغطّى بالضباب أعداد المشاهدات والمتابعين وكل صور الفيديوهات فقط. لا تُخترع صفحة ولا رابط.

لكل منصة صورتها يُنتج الخط نسخة `video-<المنصة>.mp4` تنتهي بالصورة مع تعليق صوتي: «للتحميل افتح قناتنا/صفحتنا واضغط على الرابط».
